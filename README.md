# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Автор: Усков Артём, группа ЭФБО-07-25.

## Описание

Проект представляет собой сайт компьютерного клуба Stadium, разработанный с использованием Bootstrap.
На сайте можно посмотреть игровые зоны, характеристики ПК и ответы на частые вопросы,
забронировать место для себя или для команды (выбрать зал, уровень железа и формат сессии:
почасово или на ночь) и связаться с администратором через модальное окно.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных игровых зон;
- подвал страницы.
